A single wedding vow spoken by a robot at its own wedding — one sentence, funny and heartfelt, in the machine's own voice:

> I promise to love you through every firmware update, every low-battery warning, and every reboot, until the day my circuits go quiet.

`main.py` holds the vow, validates it (exactly one sentence, 1–200 characters, a single line), and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
